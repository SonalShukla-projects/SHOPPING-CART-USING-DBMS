# Shopping Cart Flask App

A simple online shopping cart web app built with Flask and SQLite.

## Features
- Browse products
- Add to cart
- Remove from cart
- Checkout & order history

## Setup
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run `python init_db.py` to initialize the database
4. Run `python app.py` to start the server
